# Yardi Connector — что видит и чем управляет пользователь после подключения

## 1. Целевой пользователь
Property Manager/Asset Manager крупного портфеля коммерческой или многоквартирной
недвижимости, использующий Yardi (industry-стандарт для enterprise-уровня).

## 2. Момент истины после подключения
Сразу после `connect_yardi` — сводка по портфелю: occupancy rate (% занятости) по
объектам, сколько просроченных платежей, сколько открытых заявок на обслуживание.

## 3. Что пользователь видит
- Объекты недвижимости и юниты с occupancy-статусом — `list_properties`, `list_units`.
- Арендаторов и договоры (leases) с финансовыми условиями — `list_tenants`, `list_leases`.
- Дебиторскую задолженность (AR) и просрочки — `get_ar_aging_report`.
- Заявки на обслуживание (service requests) — `list_service_requests`.
- Отчёты по доходности объекта (NOI, occupancy trends) для владельцев/инвесторов —
  `get_property_financials`.
- Заявки от потенциальных арендаторов (leasing prospects) — `list_prospects`.

## 4. Чем пользователь может управлять
- Создавать заявку на обслуживание и отслеживать её выполнение — `create_service_request`.
- Регистрировать платёж и корректировать баланс арендатора — `record_payment`,
  `adjust_tenant_balance`.
- Создавать/продлевать договор аренды — `create_lease`, `renew_lease`.
- Генерировать финансовый отчёт по объекту для инвестора — `generate_financial_report`.
- Обновлять статус вакантного юнита и параметры листинга — `update_unit_listing`.

## 5. "Вау"-момент для демо потенциальному клиенту
"Смотри — говорю Webbee: 'какая occupancy по всему портфелю за этот квартал и где просрочки
самые большие?'. Она находит через `get_ar_aging_report` и `get_property_financials`
конкретные объекты — цифры, которые обычно готовит аналитик вручную несколько часов."

## 6. Что делает это "заточенным под него"
`get_property_financials` считает NOI и тренды по РЕАЛЬНОМУ портфелю именно этой
управляющей компании — данные для разговора с инвестором, а не демо-цифры.
